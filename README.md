# MyStepupHomework

Учебный проект для выполнения второго домашнего задания по Java Core. Реализует базовые утилиты в пакете `com.mystepup.homework`.

## Цель проекта
Отработка навыков:
*   Написания чистой и безопасной логики на Java (обработка граничных случаев, `null`, переполнение).
*   Работы с системой сборки Gradle (Kotlin DSL) и Gradle Wrapper.
*   Написания атомарных юнит-тестов (JUnit 5) для покрытия всех веток логики.
*   Корректной работы с Git: управление историей, игнорирование служебных файлов, разрешение конфликтов.

## Стек технологий
*   **Язык:** Java (версия 17 или выше).
*   **Система сборки:** Gradle (Kotlin DSL, `build.gradle.kts`).
*   **Тестирование:** JUnit 5.
*   **IDE:** IntelliJ IDEA.

## Функционал и задачи

В классе `com.mystepup.homework.BasicUtils` реализована базовая утилитарная логика (точный список методов соответствует требованиям второго ДЗ).

> **Примечание:** В отличие от первого задания, здесь используется пакет `com.mystepup.homework` вместо `org.example`, а также обновлён стек тестирования на JUnit 5.

## Покрытие тестами
Для каждого метода написаны атомарные тесты, проверяющие:
*   ✅ **Базовые сценарии** (нормальная работа с валидными данными).
*   ✅ **Граничные условия** (минимальные/максимальные значения, переходы между диапазонами).
*   ✅ **Краевые случаи** (`null`, пустые коллекции/массивы, отрицательные числа).
*   ✅ **Безопасность данных** (проверка, что методы не изменяют исходные входные данные там, где это не требуется).

Тесты расположены в пакете `src/test/java/com/mystepup/homework`.

## Структура проекта

*   `src/main/java/com/mystepup/homework/` — основной код проекта (класс `BasicUtils.java`).
*   `src/test/java/com/mystepup/homework/` — модульные тесты (класс `BasicUtilsTest.java`).
*   `build.gradle.kts` — конфигурация сборки проекта на Kotlin DSL.
*   `gradlew`, `gradlew.bat` — скрипты Gradle Wrapper для запуска сборки без установки Gradle.
*   `.gitignore` — правила исключения служебных файлов из репозитория.

> **Важно:** Папки `.idea`, `.gradle` и `build` исключены из репозитория, так как содержат временные файлы сборки и персональные настройки IDE.

## Как запустить проект

### Вариант 1: В IntelliJ IDEA
1.  Откройте проект через `File → Open` в IntelliJ IDEA.
2.  Дождитесь автоматической индексации и загрузки зависимостей Gradle.
3.  Запустите тесты или основной класс через интерфейс IDE (значок Play слева от метода `main` или теста).

### Вариант 2: Через терминал (Gradle Wrapper)
Используйте встроенные скрипты Gradle, чтобы проект работал даже без установленного Gradle на компьютере:

# Запуск всех тестов
./gradlew test

# Сборка проекта
./gradlew build
