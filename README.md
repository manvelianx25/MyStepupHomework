## Цель проекта

Отработать навыки:
1.  Написания чистой логики на Java (условия, циклы, работа с коллекциями и массивами).
2.  Проектирования методов с учетом граничных случаев (null, пустые коллекции, переполнение).
3.  Написания атомарных юнит-тестов для проверки каждой ветки логики.

---

## Функционал и задачи

В классе `org.example.BasicUtils` реализованы следующие методы:

| № | Метод | Описание |
| :--- | :--- | :--- |
| **1** | `isEven(int n)` | Проверка числа на чётность. |
| **2** | `checkAccess(int age)` | Проверка доступа: `Allowed` (> 18), `Denied` (< 18). |
| **3** | `isPositive(int n)` | Проверка на неотрицательность (>= 0) с использованием тернарного оператора. |
| **4** | `getGrade(int score)` | Конвертация баллов (0–100) в буквенную оценку (A–E). Вне диапазона — `Error!`. |
| **5** | `blastOff(int start)` | Генерация строки обратного отсчета до 1 с фразой «Поехали!». |
| **6** | `sumToN(int n)` | Сумма чисел от 1 до N. |
| **7** | `hasBug(String[] messages)` | Поиск строки "Bug" в массиве (без учета регистра). |
| **8** | `getEvenInRange(int start, int end)` | Получение строки чётных чисел в заданном диапазоне. |
| **9** | `findMax(int[] arr)` | Поиск максимального элемента в массиве. |
| **10** | `reverse(String[] arr)` | Разворот массива строк. Возвращает новый массив. |
| **11** | `calcAverage(List<Integer> list)` | Расчет среднего арифметического. Обработка переполнения. |
| **12** | `removeSpecificName(List<String> list, String name)` | Удаление всех вхождений имени из списка. |

## Покрытие тестами

Для каждого метода написаны атомарные тесты (JUnit 4), проверяющие:
*   ✅ **Базовые сценарии** (нормальная работа).
*   ✅ **Граничные условия** (минимальные/максимальные значения, переходы между диапазонами).
*   ✅ **Краевые случаи** (`null`, пустые коллекции/массивы, отрицательные числа).
*   ✅ **Безопасность данных** (проверка, что методы не изменяют исходные входные данные там, где это не требуется).

Тесты расположены в пакете `src/test/java/org/example`.

## 🛠 Как запустить

### Вариант 1: Через IDE (IntelliJ IDEA)
1.  Откройте проект в IntelliJ IDEA.
2.  Нажмите правой кнопкой мыши на папку `src/test/java`.
3.  Выберите **Run 'All Tests'**.
4.  Убедитесь, что все тесты прошли успешно (зеленая галочка).
