## Описание решения

В рамках третьей темы курса реализованы автотесты на базе **JUnit 5** и **AssertJ**. Основная цель работы — внедрение информативных ассертов, которые при падении дают четкое понимание того, что ожидалось и что было получено, а также настройка фильтрации и многократного прогона тестов.

Проект включает в себя:
*   **Класс `BasicUtils`**: содержит 13 методов для работы с числами, строками, коллекциями и массивами (включая методы с преднамеренными логическими ошибками для демонстрации работы ассертов).
*   **Класс `BasicUtilsTest`**: содержит 14 тестовых сценариев, покрывающих все требования задания.
*   **Gradle-конфигурация**: настроена фильтрация по тегам (`@Tag`) и принудительная установка кодировки UTF-8 для корректного отображения кириллицы в логах.

## Особенности реализации

### 1. Информативность ассертов (AssertJ)
Для выполнения требований по читаемости ошибок использован метод `.as()`.
**Пример из кода:**
```java
assertThat(actualResult)
    .as("%s isEven(%d): ожидалось %s, а получили %s",
            testInfo.getDisplayName(), number, expectedResult, actualResult)
    .isEqualTo(expectedResult);
