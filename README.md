# MyStepupHomework

Учебный проект в рамках курса Java QA Automation. Содержит практические задания по Java Core, модульному тестированию и автоматизации тестирования REST API.

## Что изучается

- **Java Core:** базовые конструкции языка, работа с данными, обработка граничных случаев, `null` и переполнения.
- **Unit-тестирование:** JUnit 5, проверка логики и граничных сценариев.
- **API-автоматизация:** REST Assured, HTTP-запросы, проверка статусов и JSON-ответов.
- **Проверки:** AssertJ и встроенные матчеры REST Assured.
- **Организация кода:** клиентский слой, конфигурация запросов и генерация тестовых данных.
- **Инструменты разработки:** Gradle Kotlin DSL, Git, GitHub и IntelliJ IDEA.

## Технологический стек

Java 17+, Gradle, JUnit 5, REST Assured, AssertJ, Jackson.

## Запуск тестов

Все тесты:

```bash
./gradlew test
```

Только API-автотесты:

```bash
./gradlew apiTest
```

Сборка проекта:

```bash
./gradlew build
```

Для запуска API-автотестов тестируемое приложение должно быть доступно по адресу `http://localhost:8080`.


*Проект развивается по мере прохождения курса и выполнения новых домашних заданий.
